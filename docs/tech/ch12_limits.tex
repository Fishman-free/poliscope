\section{已知局限与路线图}

一套以审计为核心价值的系统，对自身未完成部分应当比对已完成部分更严格。本章把分散在正文的保留项集中陈述，并给出后续优先级。

\subsection{当前版本的四条硬边界}

\begin{enumerate}[leftmargin=1.6em, itemsep=4pt]
\item \textbf{MemoBrain 上游尚未真实接入。}记忆层当前运行在内存适配器与简化折叠实现上，三层接口与隔离规则已冻结，替换为上游实现不需要改动议会与证据层，但「长程记忆防止漂移」的收益目前只有结构保证、缺少跨任务实测。
\item \textbf{证据最高只到 B 级。}首版取证管线稳定可得的是题录与摘要，全文获取与独立双抽取未完整落地，因此系统主动禁止 B 级证据单独支撑高置信因果结论。这是刻意的保守，而不是漏洞，但也意味着首版结论的证据强度上限明确。
\item \textbf{完整协议对弱模型构成负担。}第 10 章真实模型实验显示，flash 级模型在完整议会下产生大量空槽，治理机制以召回换精度的收益要在更强模型（或更轻的协议变体）上才能被公平观测。这是后续工程与实验的第一优先级。
\item \textbf{时间切片语料与人工金标准尚未产出。}ForesightBlindspot 的封闭语料、双人标注一致性数据仍在建设中；在此之前，所有评测数字都必须连同其口径（脚本化 / 真实模型、几次重复、何种裁判）一起阅读。
\end{enumerate}

\subsection{明确不做的事（YAGNI）}

首版范围刻意排除：通用全学科、自动实验设备、任意代码复现、自动元分析、模型训练平台、微服务拆分、多租户复杂权限、插件市场、移动端。这些不是被遗忘，而是对证明「组织结构提升盲点发现质量」这一首版主张没有贡献，纳入只会稀释验证强度。

\subsection{结语}

Poliscope 的赌注很具体：当多智能体研究系统的讨论从「谁的总结更流畅」转向「哪条结论被什么级别的证据支撑、谁反对、需要什么才能改判」，科研审查才真正发生。七人议会、事件账本、双图隔离与时间切片评测，都是为了让这三个问题在系统的每一层都有确定的答案——包括在系统暂时回答不了的时候，明确地把「不知道」显示出来。
